How does the internet actually work?

It isn't a cloud and it isn't one network. It's about 78,000 networks that agree, every second, to trust each other. Here is how that agreement works, in plain English.

1. The internet is a network of networks

Your home broadband, a mobile carrier, a university campus, a cloud giant's data centres: each is run independently, and each large one has its own identifying number. Engineers call these networks autonomous systems. In January 2026 there were about 77,900 of them visible on the global internet.

No single company owns "the internet". What makes these separate networks behave like one is a shared language for telling each other where things are.

2. BGP: the networks announce what they can reach

That language is the Border Gateway Protocol (BGP). Every network continuously tells its neighbours, in effect: "send me traffic for these addresses, and I'll deliver it." Neighbours pass those announcements on, choosing paths as they go. Combined, they form the internet's routing map: more than a million IPv4 routes, held by routers all over the world and updated constantly.

The important word is trust. Networks largely accept each other's announcements. That makes the system resilient (if one path fails, another is announced and traffic flows around it within minutes) but also fragile: if a network withdraws its routes by mistake, it can vanish from the internet, as Facebook did in 2021 (here's how).

3. DNS: the internet's phone book

Routers work with numeric addresses, not names. The Domain Name System translates a name like example.com into an address. It is a hierarchy that starts at the root: 13 root server identities (A to M), run by 12 organisations and copied to more than 2,000 sites worldwide, so a nearby copy can always answer.

Your device and your provider cache answers for a while, which is why DNS feels instant. But a cached address is useless if there is no route to reach it: DNS and BGP need each other.

4. The physical layer: cables, light and data centres

All of this runs on hardware. Between continents, about 600 undersea fibre-optic cables carry more than 99% of international data, as pulses of light travelling through glass at roughly 200,000 km per second, about two-thirds of the speed of light in a vacuum.

5. What happens when you open a page

  1. Your device asks DNS for the site's address (often answered from a cache).
  2. Your request leaves your provider's network and hops from network to network along the BGP map, often across an ocean.
  3. The server answers, and the reply finds its way back the same way, usually in a fraction of a second.

Why it matters

Because the internet is an agreement rather than a single machine, there is no master off switch, and real failures stay local. But it also means a single mistaken announcement can make a huge service disappear for hours. Frequently asked questions

What is BGP in simple terms?

BGP, the Border Gateway Protocol, is how the internet's networks tell each other which addresses they can deliver traffic to. Together those announcements form the internet's map of more than a million routes.

What is an autonomous system?

An independently run network with its own number, such as an internet provider, a university, a cloud company or a mobile carrier. There are about 78,000 of them.

What does DNS do?

The Domain Name System turns names people can read, like example.com, into the numeric addresses routers use. It is anchored by 13 root server identities run by 12 organisations and copied to more than 2,000 sites.

How much internet traffic goes through undersea cables?

About 600 submarine fibre-optic cables carry more than 99% of international data between continents.
